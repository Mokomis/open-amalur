# Archive contents and limitations

This public repository is a clean final source snapshot. It has a new history so that historical private release archives, game-derived payloads and unrelated/private material do not become public through old refs.

Included: project-written source, build/extraction/analysis recipes, tests, selected research/status/validation metadata, source changes through the later custom-engine stages, original-engine translation tools, local-helper source, and separate Mac coordination scripts/notes. Third-party source that is retained keeps its notices.

Excluded: game executables and DLLs, original archives and extracted media, recovered Lua corpus, raw full decompiler exports and analysis databases, GPU recordings/shader dumps, screenshots of the game, packaged APKs and compiled build trees, personal saves/configuration, credentials and signing keys. Generated asset folders and historical machine-specific build dependencies are not a substitute for obtaining your own game data.

The previous private repository and its historical checkpoint releases are retained privately by the owner under a separate archive name. They are not part of this public publication, do not contain every later local output, and should not be represented as a complete latest-state restore image. The signing key was never added to Git or release assets.

The owner requested deletion of local project working copies after publication. Public source and selected notes are the preserved deliverable; this repository does not promise that all intentionally excluded local data can be restored from GitHub. Shared tools used by other projects are outside that deletion scope.

Historical restore instructions are retained as historical documentation only. Their statements that local files remain untouched are no longer current operational instructions. Use the current README and STATUS.md.

Some Mac files were cloud placeholders. Any source-copy read failures and selection exclusions are recorded in the publication metadata; Windows counterparts were used where available. Publication verification checks file hashes and remote repository availability, not engine correctness.

Configure your own signing key before using historical packaging recipes. Standard public Android debug-signing defaults may appear in examples; no signing key is included.
