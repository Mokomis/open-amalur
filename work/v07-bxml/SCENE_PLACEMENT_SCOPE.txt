The baker consumes the independently decoded geometry JSON. It writes OMSC07:
8-byte magic OMSC07 NUL NUL, uint32 vertex count,6 float32 bounds, then triangle
soup of position3/normal3/color3 float32. This is our interchange format.
Normals are computed per face; zero-area triangles keep zero normals. Colors
are invented stable per-model preview colors, not recovered game materials.
Unknown assembly draw ranges remain a separate obligation.

Optional --fab-root selects ID.json FAB bind reports. Each report SHA256 is
checked against the original FAB file beside the selected native mesh stream,
binding it to the same asset ID and archive variant even if the report was
produced from a flat copy. Static binds require matching descriptor counts,
finite affine matrices, mapped bones, and external-reference unskinned strides
20/24/44/48/52. Bind matrices apply before the inferred instance pose. Missing
or unsupported binds omit the entire asset only with --allow-partial, recording
every omitted placement and assembly reason. Malformed matrices, descriptor
count mismatches, or source hash/provenance mismatches always fail. No mapped
bone never means implicit identity. Without --fab-root the output is explicitly
labeled a raw mesh diagnostic without FAB binding. Bind semantics remain based
on the 2018 external reference, not native confirmation.

The 79-record collection supplies props. The room shell has not been found;
this output must not be presented as the complete room or complete scene.

Missing geometry fails by default. An explicit --allow-partial records each
omitted model and loaded/requested placement totals. No successful-only total
is presented as scene completeness. Dynamic objects, materials, animation,
collision, lighting and gameplay remain outside this static geometry slice.
