This supports one consistent conjugate convention; it does not support choosing
between conventions per record. The earlier prop baker still has its original

106: all172 records with the expanded model corpus pass center and actual vertex

center, followed by conjugate rotation and translation. This is the selected
candidate profile. No vertex or bound threshold was relaxed. Native arithmetic
and live rendering equivalence remain unproven.

Current candidate baker:

amalur_shell.py uses the original scene bytes and a hash-pinned profile. It
reconstructs the primary172-record permutation, verifies original mesh and FAB
source hashes, and uses the measured assembly selector. Its private quaternion
convention conjugates stored xyz consistently; scaling is about the descriptor
center. It does not apply another bind.
It checks descriptor center/radius, all actual vertex positions against the
stored sphere plus0.1, index bounds, and assembly count words before admission.
Unsupported records require explicit --allow-partial and retain precise reasons.
Missing FAB reports can use a selected cross-archive report only when its hash
matches an actual allowed DATA/initial original; no patch precedence is inferred.

The344-record root+0x150 and75-record root+0x180 sets are excluded. Their LOD,
sorting, transparency, and draw-selection meanings need more evidence. Colors
and normals are authored diagnostics. No original material, texture, animation,
collision, gameplay, or complete scene equivalence is claimed.

The79 gameplay prop placements and the primary static render set can refer to
the same models. Never merge their geometry merely because they were extracted
through different arrays. The prior prop scene remains a separate diagnostic
until per-instance duplication is resolved.

The record associations and pose convention are corroborated through the data,
not yet a native render-consumer trace. Static sphere agreement cannot establish
live rendering equivalence. The typed references are model candidates until the
native resource dispatch is traced, even though all inspected IDs and geometry
counts agree. Stride56 is not labeled skin solely from an older importer: this
sample has static mapped descriptors and no remaps; only its positions are used.
