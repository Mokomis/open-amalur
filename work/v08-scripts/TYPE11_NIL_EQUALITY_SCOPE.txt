Portable scope

(NE). It reuses __type11_key_allowed, which captures the existing host helper
backed by the original private realm carrier membership predicate.
A user-visible userdata metatable marker or mutable public carrier.is is not
sufficient. Missing helper fails closed. No C runtime change is needed.
All table equality, arbitrary/foreign userdata equality, same-tag type11
comparison, other heterogeneous comparisons, ordered comparisons, table read
fallbacks, writes, SELF and key guards remain as before. Existing primitive
and function/nil comparison support is retained.
