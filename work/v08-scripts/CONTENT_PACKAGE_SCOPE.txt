  { int is_set; uint32_t registered_mask; uint32_t active_mask; }
Omitted trailing initializers default to unknown. All callers must recompile.
Install copies content into its own Lua-owned userdata independently from the
controller state. scene_profile_v08_set_content copies updates into that same
userdata; already captured Lua query functions observe them. Controller state
and existing queries remain independent. Invalid is_set values reject before
publication/mutation; unsetting restores explicit query errors.

Admitted argument domain: exactly one Lua numeric integer from0 through31.
Numeric strings, fractions, negative/out-of-range numbers, NaN/infinity and
other argument counts/types fail explicitly. Valid indices return a boolean
from registered_mask & active_mask. Bit31 uses an unsigned32-bit shift.
There is no coercion or wraparound guess for inputs outside the admitted domain.

report whether the user's original installation owns, licenses, or mounts DLC.
Future content loading must supply actual registered/active mount state; never
set bits merely to bypass content gates. A known empty set differs from unset.
