Admitted read domain:
  Existing plain/approved-seeall reads remain admitted.
  Exactly one additional table-valued __index hop to a plain table, or to an
  exact existing host-approved seeall module table, is admitted. The seeall
  target may fall through to plain realm globals under its existing contract.
  All other multi-hop chains, cycles, callable/userdata index values, protected
  metatables and metatables that themselves carry metatables are rejected.
  __newindex does not grant write permission and is never called by this guard.

Host predicate __amalur_read_table_allowed uses C lua_getmetatable and rawget
to inspect actual metadata. Lua getmetatable alone is insufficient: a forged
table-valued __metatable marker can hide a function-valued __index. No public
metatable behavior is changed. Predicate state is Lua-owned; source helper
captures it under the existing trusted bootstrap-global contract.
