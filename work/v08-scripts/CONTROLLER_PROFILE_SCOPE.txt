State storage is a Lua-owned userdata, captured by the input provider and retained
under a private registry key. It has no destructor, external allocation, pointer
to host storage, or device handle. scene_profile_v08_set_controller copies a new
state through protected Lua API execution; already-captured query functions see
that change. A host may release/change the argument immediately after either API
returns. A boolean is_set flag is mandatory. Unset state raises an explicit error
rather than defaulting to a controller category. Disconnection can unset state.
All signed-int32 native kinds are admitted by the comparison, but none has been
assigned a platform label here. Concurrent calls on a realm are unsupported.

All Lua allocation/error paths are protected. Installation errors require realm
destruction because provider publication and registry retention are not an atomic
transaction. Shared bootstrap already destroys failed realms. An invalid setter
flag or domain leaves prior state untouched. State and provider memory are released when
the realm closes. Runtime instruction and memory limits continue to apply; the
small native predicate itself does no I/O or unbounded native work.
