The pinned scene profile precreates from_words(0xfb,0) once during protected
installation from the trusted fresh realm's plain handle adapter. A provider
closure captures that canonical token and returns exactly one result. Later
changes or removal of public handle/carrier constructors cannot alter it.
The supported call domain is zero arguments. Extra arguments are explicit
unmodeled errors; native acceptance of arbitrary arguments is not claimed.
No object lookup, validity, dereference, existence or lifecycle behavior is
implemented. Existing providers and host-state options are unchanged.

All allocation and constructor invocation occur under the existing lua_cpcall
installer protection. Captured token lifetime belongs to Lua, with no host
allocation or retained borrowed pointer. Discard the realm after install
failure under the preexisting profile contract. The host must install this
profile before executing untrusted scene modules, as for the asset installers.
