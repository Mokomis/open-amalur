# Native river integration

Files ready in this research directory: `oa_native_water.c`, `oa_native_water.h`, `water-native.bin` (38,942,952bytes), `water-pack.json`, `water-mesh-manifest.json`. All8 river/pond draws use static native world geometry; camera/time stay live. This module does not replace scrolling-waterfall shader5.

Initialize `oa_native_water owner={0}`. Open with `oa_native_water_open(&owner,assetManager,"water-native.bin")`; copy the pack into the chosen asset root. Invoke draw after opaque/characters and a stable full-viewport RGBA8+depth snapshot, before bloom/final. Pass live GL VP/eye, snapshot texture IDs, caller's native inverse depth pair, live time, ambient cube and environment. The environment supplies sun direction/color, shadow color, water fog triplet(80,.01,1). The module derives saved D3D clip.z=.5*(GLclip.z+clip.w) and flips each final sample's Y for lower-left GLES snapshots.

`oa_native_water_gpu_close()` deletes GPU objects while retaining CPU pack, so subsequent draw automatically recreates them. `oa_native_water_close()` frees all owned memory. Call gpu_close before losing the old context, as with existing renderer resources.

Host import library needs three additional exports in its .def: `glBlendEquation`, `glCullFace`, `glFrontFace`. They are existing ANGLE entry points, not new dependencies. A private research import library was generated for verification; shared .def/import libraries were not edited.

The module explicitly sets depth LEQUAL/writeOFF, SRC_ALPHA blend, back cull, OpenGL frontCCW. Retained world triangle cross products agree with outward normals. It leaves depth writes ON, blendOFF, active texture0 and VAO0 after draw. Root should establish subsequent render-state requirements normally. Point lights are four actual authored world-space point-light records selected by the native bridge draw; the captured PS946 path disables them. This selection is frame-scoped and static Noon evidence, not a general live light-grid producer. Per-instance native tint/luminance values are preserved.

`oa_native_water_contains(owner,materialId,worldPosition,tolerance)` supplies only a bounded instance AABB test. It must not hide entire shared-material batches. Prefer generator-side triangle classification with material+instance bounds and a precise geometry join. Keep old river outside the8 recovered instances. Manifest bounds span actual world coordinates; the broad pln_riverpond planes overlap riverwaterfall meshes of other materials, which is intended.

Pack top-mip pixels are decoded from exact BC1/BC3 recorded bytes and the module generates filtered mipmaps. Native original compressed mipchains are retained under resources/, but are not yet uploaded as their authored lower mip levels. RGBA CPU endpoint/interpolation rounding and generated mipmaps can differ slightly from native compressed sampling. This is disclosed fidelity scope, not a color adjustment. Every recorded source image is UNORM; no sRGB conversion is introduced. The resource pack contains all base/normal/foam/detail/refraction textures plus the4 actual reflection probes, with original material/draw mapping. Native material declared SpecularColor is unused in the recovered pixel equation and is retained without inventing a contribution.

Validation: material first92-byte match for all8 native draws; HLSL/SPIR-V reviewed equations; GLES3 shader compile+link via glslangValidator; MSVC C11 compile under actual host headers; real Windows pack loader/bounds/lifecycle smoke. Separate ANGLE offscreen shader/upload/draw/recreation results are in gpu-check.log when available. None of these establish visual parity; root must compare actual original-camera render and normal camera after integrating.
